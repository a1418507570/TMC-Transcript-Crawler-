# TMC Transcript Crawler

一个用于在网页端会议纪要/转写页面中，自动滚动抓取全部发言内容的小工具。

它会：

- 自动查找滚动容器
- 边滚动边抓取当前页面中的转写行
- 使用 `pid` 去重，避免重复内容
- 将结果整理为 `[时间] 说话人: 内容` 的格式
- 自动尝试复制到剪贴板
- 同时在控制台完整输出，方便手动复制

## 功能特性

- **自动滚动抓取**：持续向下滚动直到到底部
- **基于 `pid` 去重**：避免重复记录同一段内容
- **容错处理**：未找到容器时会给出错误提示
- **剪贴板复制**：优先自动复制，失败时可手动复制控制台内容
- **零依赖**：直接在浏览器控制台运行即可

## 使用方式

### 1. 打开目标页面

进入包含会议转写内容的网页，并确保页面中存在以下相关 DOM 结构：

- 滚动容器：`.minutes-module-list`
- 每一行内容：`.minutes-module-row`
- 段落 id：`.paragraph-module_paragraph__79pMd`
- 说话人：`.paragraph-module_speaker-name__afSbd`
- 开始时间：`.minutes-module-p-start-time`
- 发言内容：`.minutes-module-sentences`

> 如果目标网页的类名发生变化，需要同步修改 `script.js` 中的选择器。

### 2. 打开浏览器开发者工具

通常可以使用：

- macOS: `Option + Command + I`
- Windows: `F12` 或 `Ctrl + Shift + I`

切换到 **Console** 面板。

### 3. 粘贴并运行脚本

将 `script.js` 的全部内容粘贴到控制台后执行。

### 4. 等待抓取完成

脚本运行时会：

- 自动滚动页面
- 实时收集转写内容
- 最终输出总条数
- 打印完整文本
- 尝试复制到剪贴板

## 输出示例

```text
[00:01] 张三: 大家下午好，我们开始今天的会议
[00:08] 李四: 好的，我先同步一下当前进度
[00:20] 王五: 关于这个问题，我补充一点
```

## 适用场景

- 会议纪要页面内容导出
- 网页转写结果整理
- 手动导出不方便时的临时抓取
- 需要快速复制全文到文档或笔记工具时

## 原理说明

脚本核心流程如下：

1. 定位滚动容器 `.minutes-module-list`
2. 遍历当前可见区域内的 `.minutes-module-row`
3. 提取每一行中的 `pid`、说话人、时间、内容
4. 用 `Map` 以 `pid` 为 key 做去重
5. 持续向下滚动并等待页面渲染
6. 当滚动位置不再变化时，判定已到末尾
7. 拼接全部结果并输出/复制

## 注意事项

- 该脚本依赖目标页面的 DOM 类名，页面改版后可能失效
- 运行时请尽量保持目标标签页处于激活状态
- 某些浏览器环境下，控制台脚本调用剪贴板 API 可能被拦截
- 如果自动复制失败，可直接从控制台日志中手动复制内容
